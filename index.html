HTML y Lecciones para Moodle

Diseña páginas, lecciones y temas con estilos limpios compatibles con EducaMadrid. Incluye tarjetas didácticas, acordeones interactivos sin JS, tablas adaptables y validador de seguridad para Atto/TinyMCE.

📝

Cuestionarios GIFT y Moodle XML

Genera bancos completos de preguntas tipo test, opción múltiple, verdadero/falso, emparejamiento y respuesta corta listos para importar con 1 clic en el Banco de Preguntas del Aula Virtual.

📄

Documentos DOCX y PDFs Educativos

Procesa libros y currículos oficiales LOMLOE en PDF con pdfplumber y pypdf. Compila rúbricas, guías docentes y fichas de actividades en formato DOCX y PDF de alta fidelidad con Pandoc y LibreOffice.

🖼️

Imágenes y Diagramas Optimizados

Compresión automática de imágenes con ImageMagick y OptiPNG para no agotar la cuota de almacenamiento del centro escolar (<350 KB). Generación de mapas conceptuales con Graphviz.

🤖

OpenCode v2: El Único Agente Preinstalado

A diferencia de entornos formativos para alumnos, esta máquina virtual no incluye tutor socrático ni preguntas retóricas. OpenCode v2 actúa como un copiloto directo y eficiente para el profesorado:

🚫 Cero Rodeos Socráticos Entrega el material didáctico completo y maquetado desde la primera petición.
⚡ Modo Terminal y Web Úsalo en consola (opencode) o como servidor web accesible en http://localhost:49374.
🧹 Sin Java ni Sysadmin Sistema depurado y ligero, sin cargas de desarrollo en Java ni herramientas de servidores.

🔑 Credenciales y Configuración de Puertos

Parámetro Valor Detalle
