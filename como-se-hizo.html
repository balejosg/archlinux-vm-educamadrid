🛠️ Documentación Técnica y Proceso de Ingeniería

¿Cómo se construyó la máquina virtual con OpenCode v2 para EducaMadrid?

Este documento desglosa las decisiones de diseño, la transformación del sistema base, la depuración de dependencias y la configuración de herramientas multiformato orientadas a la docencia.

01. Del Entorno de Alumno al Entorno de Docente

Las máquinas virtuales pedagógicas tradicionales suelen construirse pensando en el alumno (con compiladores de Java y tutores que guían mediante preguntas socráticas). Para un **docente**, este planteamiento resulta contraproducente: el profesor necesita una herramienta de **alta productividad**, que genere materiales completos y listos para publicar en el **Aula Virtual (Moodle 4.x)** de EducaMadrid.

❌ Eliminado: Toolchain de Java (OpenJDK 21, Maven), IntelliJ IDEA, contenedores Docker, brokers MQTT Mosquitto, herramientas de métricas energéticas (PowerTOP, Scaphandre) y tutor socrático.
✅ Incorporado: OpenCode v2 (único agente), procesamiento integral de PDFs, conversión y maquetación DOCX con Pandoc y LibreOffice headless, compresión web de imágenes con ImageMagick y OptiPNG, generadores de cuestionarios GIFT y plantillas HTML accesibles (DUA).

02. Integración de OpenCode v2 como Único Agente

OpenCode v2 introduce una arquitectura cliente-servidor con un demonio de fondo que sincroniza el trabajo tanto en la terminal interactiva como a través de su interfaz web:

// Modo 1: Consola interactiva para el profesor

cd ~/trabajo && opencode

// Modo 2: Servidor web accesible desde el navegador del host

opencode serve --port 49374

Gracias al reenvío de puertos NAT configurado en VirtualBox (49374 ➔ 49374), el profesor puede interactuar con el agente cómodamente desde su navegador habitual en http://localhost:49374 mientras la máquina corre en segundo plano.

03. El Toolchain Multiformato

📄 Procesamiento de PDFs

pdfplumber, pypdf y poppler para extraer texto de decretos curriculares oficiales y libros de texto. weasyprint para compilar apuntes a PDF de alta resolución.

📝 Documentos DOCX

pandoc y python-docx para generar y estructurar guías didácticas, rúbricas de evaluación y fichas de ejercicios directamente en formato Word.

🖼️ Imágenes y Diagramas

imagemagick y optipng para optimizar fotografías a tamaños web (<350 KB). graphviz (dot) para trazar mapas conceptuales y esquemas de contenido.

🌐 HTML para Moodle

Estilos responsivos diseñados para el tema de EducaMadrid con tarjetas, acordeones desplegables y validador de código seguro libre de scripts no admitidos por el LMS.

04. Reproducción Automatizada en Cualquier Entorno

Todo el proceso de aprovisionamiento está codificado en scripts bash reproducibles en el repositorio oficial:

# 1. Clonar el repositorio de construcción

git clone https://github.com/balejosg/archlinux-vm-educamadrid.git

cd archlinux-vm-educamadrid

# 2. Construir e importar la máquina en VirtualBox

bash scripts/crear-vm-educamadrid.sh

# 3. Exportar el appliance comprimido .ova

bash scripts/exportar-ova.sh
